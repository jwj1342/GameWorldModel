# 资产真值的轴向边界与检索资格

资产生成器按所选静态GLB的真实XYZ边界等比生成extent，初始半高和碰撞尺寸沿用这一边界。边界读取沿用现有GLB解析器，遍历活动场景的每个节点实例，并按Three默认Box3方式变换局部包围盒；不从随机表面采样或排序后的比例推断高度。不再随机交换尺寸轴；如将来增加随机朝向，应显式写入姿态并重新计算支撑高度。

稀疏/量化/压缩位置、蒙皮、形变等本实现不支持的几何不提供部分边界，所选资产沿用基本体回退。当前未在完整Kenney库上复测支持率；这次修复不宣称所有资产都能使用。新生成的资产批次应重新制作并保存身份，旧视频与旧真值不会被自动改写。

`--use-assets`只需要可用资产库；生成尺寸不依赖`assets.shape_cache`。形状重排与形状指标仍使用原有比例缓存，不改变其格式。资产目录缓存按库路径与目录文件身份区分，避免一个进程切换库后沿用前一个库。

形状排序开启且观测比例可用时，`choose_assets()`先筛出文字分达到`min_score`的候选，再重排。形状分不能取消或赋予语义资格；没有合格候选仍回退基本体。默认`shape_weight=0`保持旧路径，不改变现有默认选择。

回归使用可检查顶点的合成GLB、12个生成场景及24个资产尺寸样本；Three的真实GLTFLoader核对显示边界、碰撞框与初始底部。合成样本不是Kenney全库效果或模型精度实验。
