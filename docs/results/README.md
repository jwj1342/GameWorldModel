# 结果

## 历史结果的使用边界

`editability.json` 保留旧判定器产生的历史记录（17/20），不代表修补后的有效通过率。
PR25 的判定修补尚未传播到本分支；传播后须离线重评保存响应，无法重评的条目标记不可判定。
直接代码入口目前只证明语法检查与打包，尚未执行浏览器验证或严格配平相机、输入和调用预算。
宿主碰撞体/位姿修补后，受影响的运行实验需重新验证；现有材料不足以证明DSL优于或劣于直接代码。
保留历史文件，不改写原始结果，也不将未评测项记为零或成功。

每个文件夹是一次运行里值得看的东西。report.md 是报告，program.json 是场景程序，overlay.mp4 把感知结果画回了视频上，keyframes 是送给模型看的关键帧，render 里是重新渲染的画面和 ID、深度通道，playtest 里是自动试玩的截图和判定。

文件夹名不带后缀的是不调用模型、直接从证据翻译的版本。带 glm 的是 GLM-4.6V 三阶段生成加两轮修订的版本。handwritten_playground 用的是合成片段的真值感知，handwritten_playground_neural 用的是同一段片段的神经感知。
