# 场景说明

## 布局（依据 24 张照片 + 稀疏点云逐物体定位）

长条形客厅，x∈[-1.36,1.30]，z∈[-2.45,3.80]，y 朝上、地面 y=0：

- **南墙** (z=-2.45)：窗户 + 两侧落地窗帘，窗前是深蓝色 recliner 躺椅（带棕白花靠垫），前面是弯木脚凳
- **东墙** (x=1.30)：壁炉墙式布局——南侧凹龛（桌游 + 打印机 + 粉色画）、中间凸出墙垛挂电视（电视墙上方有画框和挂钟）、北侧凹龛（书 + 唱片 + 蝴蝶兰），再往北是木书架（顶上地球仪 + 纸箱）
- **北墙** (z=3.80)：窗户（灰色罗马帘）+ 暖气片，窗前黑色三角钢琴（盖子撑起、琴凳、花纹地毯、纸箱）
- **西墙** (x=-1.36)：灰色转角沙发（主体 + 南端扶手 + 北侧贵妃榻），门洞 z∈[1.44,2.24]，白色门开约 90°（铰链在北门框），门后是黑暗的走廊
- 中间：深绿地毯上叠浅灰蓝地毯，拖鞋、C 形边几（木面黑金属腿，桌面板悬在沙发座上方，碗/玻璃水瓶/玻璃杯/水瓶在上面）
- 电视墙前：低音炮、左右音箱（带支架）、玻璃电视柜（内含中置音箱和功放）

## 动静判断

- **判为不能动 (static)**：floor、walls、window（及南窗）、alcove_shelves（嵌入式）、sofa（大转角沙发）、tv_stand（满载玻璃机柜）、piano（三角钢琴太重）、radiator、curtains、bookshelf、wall_decor，以及三块地毯（rug_dark、rug_light、piano_rug——大面积地毯压在家具底下，实际中更接近"铺在地面"而非"随手挪动"，且叠放的活动地毯在物理引擎里不稳定）
- **判为能动 (movable)**：door（hinge，绕北门框竖轴，limit [-1.2,1.6]，开→关）、armchair、armchair_cushion、footstool、coffee_table、bowl、carafe、wine_glass、slipper_left/right、subwoofer、tv（立在柜上）、speaker_left/right（连支架）、plant、piano_bench，以及额外物体（keyboard、side_table、printer、bottle、cardboard_box、air_purifier）

## 已知不足

- 空气净化器的精确位置对不上所有视角（点云里它贴着西墙、半藏在沙发后，前后视角三角化结果不一致），放在了贵妃榻与门之间
- 钢琴盖用一块平直斜板近似（真琴盖是弧形的），琴身尾部用方盒近似弧线
- 躺椅的 recliner 曲面、沙发的软包褶皱都用方块近似，轮廓偏硬
- 植物叶子是 12 片薄盒，剪影比真实龙血树稀疏
- 走廊只做了黑盒子（照片里只能看到黑白格地板的一角）
