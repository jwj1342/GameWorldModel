# 光照归因（2026-11-26，Mac）

`lighting-<几何>-<灯光>/`：几何（`describe`）和灯光（`environment`）各取第一次运行的最终版或中途快照，纯色模式，39 个留出视角。

| 几何 | 灯光 | PSNR | SSIM | LPIPS | 深度差中位数 | 交互清单 |
|---|---|---|---|---|---|---|
| 最终版 | 最终版 | 13.89 | 0.488 | 0.613 | 3.8 厘米 | 29/30 |
| 最终版 | 中途 | 15.77 | 0.515 | 0.593 | 3.8 厘米 | 29/30 |
| 中途 | 最终版 | 13.91 | 0.490 | 0.611 | 3.9 厘米 | 28/30 |
| 中途 | 中途 | 15.42 | 0.513 | 0.593 | 3.9 厘米 | 28/30 |

几何和灯光同源的两格复现了文档里的 13.89 和 15.42 dB。

做法上和 PR #98 评论里的命令有一处不同：`eval` 只把 `scene.js` 和 `materials.json` 拷进运行目录，
所以 `scene.js` 从同目录的 `geometry.js`、`lighting.js` 转导出会加载失败。这里改成把两份源码原样
内嵌成 data URL 再转导出，没有改仓库代码。因此 `results.json` 里的 `code_size` 对这四次没有意义。
